Como funcionam os Favoritos Ocultos?

Links protegidos podem levantar suspeitas se ficarem visíveis no histórico ou na barra de favoritos. Com os Favoritos Ocultos, seu link se parece exatamente com um favorito comum (ex: um artigo da Wikipédia ou página do Gmail).

Passo a passo para configurar:

  1. Crie um link protegido com senha se ainda não o tiver feito.
  2. Arraste o botão "Descriptografar" abaixo diretamente para a sua barra de favoritos do navegador:
    Descriptografar (Arraste para a barra)
    Dica: Você pode renomear este favorito para "Gmail" clicando com o botão direito nele na sua barra de favoritos.
  3. Preencha os dados do formulário abaixo para gerar o favorito disfarçado e arraste-o também para a sua barra.
  4. Como abrir o link secreto: Clique primeiro no favorito disfarçado e, em seguida, clique no botão "Descriptografar" da sua barra!
